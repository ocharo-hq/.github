# Ocharo organization profile

*Last updated: 2026-09-29*

This repository contains the GitHub organization profile for [Ocharo HQ](https://github.com/ocharo-hq).

## Profile

[`profile/README.md`](profile/README.md) is the public introduction shown on the organization overview when this repository is published as **`ocharo-hq/.github` with public visibility**.

GitHub reads organization profiles from a public `.github` repository. A repository named `ocharo-hq` does not supply the organization's profile automatically. See [GitHub's organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

## Related repositories

- `ocharo-hq` holds the main brand and portfolio README.
- `ocharo-ws` is the main engineering workspace. It is maintained in the private `ocharo-hq/ocharo-ws` repository.

This public repository owns the organization profile and shared GitHub metadata. Keep links to private engineering repositories out of the public profile.

Keep this repository public-safe. Shared issue templates or contribution defaults can be added when there is an agreed need; none are required for the profile.
