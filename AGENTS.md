# Ocharo organization profile — contributor instructions

*Last updated: 2026-09-29*

- Treat every file in this repository as intended for public access.
- Keep `profile/README.md` short, accurate and understandable outside the engineering team.
- GitHub requires a public repository named `.github` to render the public organization profile.
- Keep the fuller brand overview in `ocharo-hq`; keep setup and repository coordination in `ocharo-ws`.
- Distinguish plans from shipped applications and verified remote links from intended addresses.
- Do not add customer information, private business records, credentials or local machine paths.
- Check Markdown links and inspect the diff. There is no application build in this repository.
- Preserve unrelated work and report publication separately from local file changes.
